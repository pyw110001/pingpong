# Vary: 3D Air Hockey Game (3D 桌面冰球/气垫球)

一个基于最新 **Three.js (WebGPU Renderer)** 和 **Vite** 构建的高画质 3D 桌面冰球游戏。虽然项目模板最初名为 3D Ping Pong，但其实际玩法、碰撞物理和视觉呈现均模拟了经典的桌面气垫球（Air Hockey）运动。

---

## 🎮 游戏特色与核心玩法

1. **真实物理与碰撞机制**：
   - 冰球限制于桌面二维运动，具备碰撞轨道反弹、挡板物理反射以及进球插槽检测。
   - 速度自适应：碰撞反弹时，冰球会带有轻微的加速机制，保证游戏对抗的激烈度。
2. **智能化 AI 挡板**：
   - 当冰球朝向 AI 移动时，AI 会智能预测拦截点并主动出击；冰球远离时，AI 会自动退回守门线进行防守。
3. **多维操控支持**：
   - **手势操控**（Kiosk 推荐）：通过摄像头识别右手腕位置，平滑映射挡板；举右手过肩可发球/继续。
   - **鼠标操控**：通过光标位置平滑映射挡板，摄像头不可用时自动作为备用输入。
   - **键盘操控**：使用 `W`、`A`、`S`、`D` 或方向键移动。
   - **移动触摸**：全面支持手机/平板端的触屏滑动操控。
4. **内置设置面板（⚙）**：
   - 游戏中按 **`P` 键** 或点击右上角齿轮，可开启全功能实时控制面板，动态调整光照、阴影、材质粗糙度、雾效、GTAO 细节、SSR 反射参数等。
5. **自由视角切换**：
   - 默认采用透视对战视角。按 **`F` 键** 可切换到自由轨道相机模式（OrbitControls），通过鼠标旋转、缩放多角度观赏场景。

## 🛠 技术栈与依赖库

- **核心框架 & 渲染器**：[Three.js](https://threejs.org/) (版本 `^0.183.2`)，使用了最新的 `WebGPURenderer` 进行前沿的 GPU 渲染。
- **着色器语言**：TSL (Three.js Shading Language)。所有的后期反射（Screen Space Reflection, SSR）和环境光遮蔽（GTAO）均使用 TSL 节点搭建，避免了传统 GLSL 繁杂的编译。
- **环境光照**：基于 [Polyhaven](https://polyhaven.com/) 提供的 HDR 贴图实现的基于图像的照明 (IBL)。
- **音频合成**：完全基于原生 **Web Audio API** 实现。无需加载任何 MP3 资源，所有球体碰撞、划痕、主题背景音乐均是通过代码实时调制振荡器（Oscillators）、滤波器（Filters）和增益节点（Gain）生成的。
- **姿态识别**：基于 **MediaPipe Pose Landmarker** 在浏览器中识别右手腕关键点，用于 Kiosk 体感控制。
- **开发与构建工具**：Vite 6，提供极速的热重载与构建服务。

## 🚀 快速开始

### 依赖安装

确保本地已安装 [Node.js](https://nodejs.org/) (推荐 v18+)，在项目根目录运行：

```bash
npm install
```

### 启动开发服务器

启动项目并在浏览器中预览（默认已配置为端口 `5178`）：

```bash
npm run dev
```
启动后，打开浏览器访问：[http://localhost:5178/](http://localhost:5178/)

### Kiosk 手势控制

手势控制会在页面加载后请求摄像头权限。浏览器通常只允许在 `localhost` 或 HTTPS 环境中访问摄像头，因此 Kiosk 部署时请使用 HTTPS 地址，或在本机浏览器访问 `http://localhost:5178/`。

- 左侧预览窗口会显示镜像摄像头画面、识别骨架和右手腕标记，便于现场判断手势是否被识别。
- 预览窗口下方可以在 `手势` 和 `鼠标` 之间切换；切到 `鼠标` 后仍显示识别预览，但不再用手势控制挡板。
- 在 `手势` 模式下握拳会按顺序循环切换北极、地狱、派对、复古、禅意模式。
- 右手腕左右移动控制挡板横向位置。
- 右手腕上下移动控制挡板在己方半场的前后位置。
- 举右手高过右肩并保持约 0.35 秒，可触发发球、重开或进入下一局。
- 摄像头不可用、权限被拒绝或人体离开画面时，鼠标、触摸和键盘输入仍可继续操作。

### 构建打包

将项目打包生成高压缩的静态网页资源：

```bash
npm run build
```

可以使用 preview 命令预览打包后的生产环境代码：

```bash
npm run preview
```
